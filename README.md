I Am not generated 

> "Desconfie de todo mundo. Os gerados estão aumentando."

Um jogo investigativo em estilo terminal baseado em texto, com estética de terror analógico (Analog Horror) e mecânicas de "Papers, Please". Desenvolvido em *C, o projeto tem o objetivo de educar os jogadores sobre os riscos das inteligências artificiais geradoras e como identificar *deepfakes, sem abrir mão de uma atmosfera opressiva e uma gameplay engajadora.

---

##  Sobre o Projeto Acadêmico

Este projeto foi desenvolvido como requisito avaliativo para o curso de Análise e Desenvolvimento de Sistemas da *CESAR School* (2026). 

###  O Desafio Educacional
Mais do que um jogo de investigação, o sistema atua como uma ferramenta lúdica. O jogador é forçado a consultar um *"Guia estilo Alerta do governo"* para aprender a identificar erros comuns em IAs geradoras, aplicando esse conhecimento em tempo real.

---

## Mecânicas Principais

O núcleo do jogo funciona através de um ciclo de interrogatório e verificação:

*   *Sistema de Diálogos Dinâmicos:* Lógica de programação ramificada entre diálogos, onde respostas estranhas guiam a investigação.
*   *Análise Forense de Assets:* O jogador possui ferramentas para focar em discrepâncias visuais geradas por IA (Mãos, Olhos, Dentes, Paisagem).
*   *O Veredito:* Dois botões principais de decisão ("IA" e "Humano"). Erros alimentam um Counter interno que afeta a ambientação e a dificuldade.
*   *Modos de Jogo:* Campanha com dificuldade progressiva, Modo Treino e um Modo com Tempo.
*   *Finais Múltiplos:* O destino da run é moldado pela taxa de acertos e falhas ao longo dos interrogatórios.
